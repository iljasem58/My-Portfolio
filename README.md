# Hi, I'm Ilja 👋

This is my portfolio. Four years shipping code, now making sure what gets
built actually gets used — the site walks through a production RAG platform, Jira ticket analyzer and a CI/CD pipeline analyzer where I
pushed the same ingest → analyze → integrate approach to solve problems the
team kept running into.

No framework, no build step, no bundler drama. Just static HTML/CSS/JS and
a Google Fonts stylesheet — because a portfolio about shipping things shouldn't need a pipeline to run.

## Run it

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

Or just open `index.html` in a browser. Nothing here depends on a server.

## What's inside

```
index.html    the whole site
css/style.css styles
js/main.js    interaction (theme toggle, etc.)
assets/       images
```
